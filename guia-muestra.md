# Guía de muestra — Kit de Gestión para Micro-Negocio

**Versión gratuita de muestra** de Chimindo IA. Incluye una plantilla de ventas lista para usar en Excel, Google Sheets o LibreOffice.

## Qué incluye esta muestra

- `ventas-muestra.csv` — plantilla de ventas con 5 filas de ejemplo (borra las de ejemplo y escribe las tuyas)
- Columnas: Fecha, Venta, Producto, Cantidad, Precio Unitario, Total, Ganancia, Categoría, Notas

## Cómo usar la muestra

1. Descarga `ventas-muestra.csv`
2. Ábrelo en Excel, Google Sheets o LibreOffice Calc
3. Borra las filas de ejemplo (fila 2 en adelante)
4. Escribe tus propias ventas debajo
5. Suma la columna Total para ver tu ingreso del mes

## Qué incluye el kit completo ($19 USD)

El kit completo tiene 5 plantillas:
1. **Ventas** — total y ganancia automáticos
2. **Gastos** — totales y gasto por categoría
3. **Flujo de caja** — saldo acumulado
4. **Cobranzas** — días de atraso y estado
5. **Inventario** — alerta de reposición

Más guía de inicio en 5 minutos. Funciona sin macros.
